# Kotaru — paquete de contexto para Claude

Este paquete convierte la idea de **Kotaru** en un proyecto ejecutable por Claude. El producto se inspira en la categoría de compañeros virtuales animados, pero no debe copiar marcas, personajes, textos, diseños, código ni activos de terceros.

Decisiones incorporadas: mercado USA con expansión internacional, diseño moderno, personajes manga originales y presupuesto operativo inicial máximo de USD 1,000 mensuales.

## Orden de uso

1. Cree un proyecto nuevo en Claude.
2. Pegue íntegramente `01_CLAUDE_PROJECT_INSTRUCTIONS.md` en **Project Instructions**.
3. Añada al conocimiento del proyecto los archivos `02` a `08`.
4. Inicie una conversación nueva y pegue `00_MASTER_BUILD_PROMPT.md`.
5. Pida a Claude trabajar por hitos y entregar código ejecutable, pruebas y documentación en cada hito.

## Archivos

- `00_MASTER_BUILD_PROMPT.md`: encargo inicial para diseñar y construir el MVP.
- `01_CLAUDE_PROJECT_INSTRUCTIONS.md`: reglas permanentes de Claude.
- `02_PRODUCT_BRIEF.md`: visión, usuarios, propuesta de valor y alcance.
- `03_ARCHITECTURE_AND_AI_ROUTING.md`: arquitectura técnica y router multiproveedor.
- `04_VOICE_ECONOMICS_AND_PLANS.md`: modelo de costos, límites y monetización.
- `05_UX_PERSONAS_AND_MEMORY.md`: experiencia, personajes y memoria.
- `06_SAFETY_PRIVACY_AND_COMPLIANCE.md`: seguridad, privacidad y límites del producto.
- `07_ROADMAP_AND_ACCEPTANCE_CRITERIA.md`: fases y criterios verificables.
- `08_DECISIONS_AND_OPEN_QUESTIONS.md`: decisiones asumidas y asuntos por resolver.
- `09_BRAND_AND_ART_DIRECTION.md`: identidad moderna, manga original y cast inicial.

## Principio central

La ventaja no será afirmar que la IA es “más inteligente”. Será ofrecer una relación más accesible y duradera: más minutos de voz, buena memoria, baja latencia, personajes expresivos y precios sostenibles gracias a un router que pueda usar proveedores chinos o internacionales de menor costo.
